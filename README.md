# 🥣 Bal Aahar — Indian Healing Recipes for Little Ones (6m to 4y)

> **Comforting Indian Home Recipes & Pediatric Recovery Nutrition**  
> Tailored for infants, toddlers, and preschoolers recovering from fever, cold, tummy trouble, dehydration, and other common childhood conditions.

---

## 🌿 Highlights

- **Scandinavian Minimalist Aesthetic**: A warm, calming design inspired by premium child-wellness brands (like Mushie) utilizing soft earth tones (terracotta clay, sage green, linen cream), rounded claymorphic cards, and delicate floating background motifs.
- **75 Curated Healing Recipes**: Spanning 25 distinct childhood conditions across 3 age groups (6–12 months, 12–24 months, 2–4 years).
- **Smart Multi-Symptom Harmony**: Select up to 3 conditions simultaneously—the system dynamically determines clinical urgency and recommends **one optimal healing bowl** safe for all symptoms, along with a harmony explanation.
- **Pediatric Safety Protocol**: Automatically displays a **Pediatrician Consultation Card** when 4 or more symptoms are selected, advising professional evaluation for complex simultaneous illnesses. Under 1 year, honey, sugar, and salt are strictly excluded.
- **Active Cooking Helper**: Built-in countdown cooking timer with pause, resume, reset, and audio chime notification.

---

## 👶 Age Groups Supported

1. **Infants (6 to 12 months)**
   - Smooth purees, watery broths, and starches.
   - **Zero salt, zero sugar, zero honey**.
2. **Toddlers (12 to 24 months)**
   - Soft mashed textures with mild, warming digestive herbs (cumin, turmeric, hing).
3. **Preschoolers (2 to 4 years)**
   - Soft solids, easy-to-chew nutrient-dense meals.

## 🚀 Getting Started

Simply clone or download this repository and open `index.html` in your web browser:

```bash
# Clone the repository
git clone https://github.com/<your-username>/bal-ahar.git

# Navigate into the folder
cd bal-ahar

# Open directly in browser or serve with any static server
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.
